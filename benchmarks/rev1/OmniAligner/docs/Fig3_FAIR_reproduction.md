# Fig. 3 FAIR landmark benchmark

Notebook: `../notebooks/Fig3_FAIR_landmark_benchmark.ipynb`.

The first cell clones the public rev1 repository, downloads the self-contained landmark archive, and installs four pinned numeric/plotting dependencies. The notebook calculates every score from arrays using functions printed in its cells. It does not rerun registration.

## Inputs and source

The release asset `rev1-fig3-fair-landmarks.tar.gz` contains ten lossless landmark NPZs, a source/hash manifest, and reference arrays generated by the archived metric implementation. All eight saved landmarks are retained; the original scoring protocol uses the first four in source order. Source files are `Figure2_HE_3D.ipynb` cells 5–7 and 9 (zero-based) and `omnialigner/metrics/regbenchmark_py/{__init__,utils,tre,rtre}.py`. Absolute paths in the manifest are provenance only, not runtime dependencies.

Archive SHA256: `38020db057f3914c78aa1bf631409bedfca3a061213304d37c8cd846c11936d4`; size 398,772 bytes.

## Calculations and historical display

- Prostate: 259 adjacent pairs; pairwise TRE and cumulative mean-displacement aTRE.
- Liver: 47 globally corresponding layers; 46 adjacent-pair TRE records and 47 linear-fit aTRE records.
- Within-pair/layer landmark means are summarized with sample standard deviation (ddof=1).
- The historical 0.46 factor is retained for numerical parity only. The coordinate chain is not physically calibrated; do not call these values micrometre accuracy.
- The directly recomputed table retains all Liver aTRE layers and all CODA calculations.
- The separate historical display drops the final Liver aTRE layer and substitutes six fixed CODA Prostate entries from the old plotting code. These entries are clearly marked as historical fixed references, not recomputed scores. Their external attribution has not been established here.
- Historical colours use `(value-column_min)/(RAW-column_min)`, clipped to [0,1].

Outputs include per-point arrays, per-pair/layer CSVs, complete recomputed summaries, output-coordinate-unit summaries, and two separate PDF/PNG figures. The original manuscript PDFs are not modified.

## Validation

All 20 metric arrays (8,335 values) match the original implementation, maximum absolute difference 2.28e-13 on macOS (4.55e-13 on Linux). The 80-cell historical display also matches the original plotting transformation (78 finite cells, two missing CODA minima). Computation was executed on Python 3.10 with the pinned packages. A subsequent clean macOS Python 3.10 execution ran the unmodified public `git clone`, `wget` and `pip` bootstrap and every calculation/plotting cell successfully in 260 seconds. No private data or server directory was used. See `../validation/fig3_fair/` for exact reports.
